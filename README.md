# week1-python-user-profile
Week 1 Python Project for my Data Science Internship at Developers Arena.

## Project Overview

This project was developed as part of my Week 1 Data Science Internship.

The program asks the user to enter their name, age, and favorite hobby. It then generates a personalized welcome message based on the information provided by the user.

## Objectives

The main objectives of this project are:

- Understand basic Python syntax
- Learn how to take user input using `input()`
- Store information using variables
- Use f-strings for formatted output
- Practice basic string handling
- Display a personalized message

## Technologies Used

- Python 3
- Python IDLE
- GitHub

## Features

- Accepts the user's name
- Accepts the user's age
- Accepts the user's favorite hobby
- Generates a personalized welcome message
- Uses f-strings for formatted output
